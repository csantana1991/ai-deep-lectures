# AI Deep Lectures

Unofficial study companion for deep learning, NLP, and computer vision.

- Public repo: https://github.com/csantana1991/ai-deep-lectures
- Site (after Pages is on): https://csantana1991.github.io/ai-deep-lectures/

Each lecture opens a real public recording (MIT 6.S191, Stanford CS224N, Stanford CS231n). Play mounts an in-page player. Open on YouTube is the fallback if the embed is blocked.
